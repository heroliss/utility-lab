# Liss Utilities

两个旧桌面工具的现代浏览器重建：**Unicode 字符表**与**汉字数字批量重命名**。采用暗色响应式工作区，所有字符检索、文件名转换与文件处理都在本机浏览器中完成，不上传文件，也不需要账号或服务器数据库。

## 使用

```powershell
npm ci
npm run dev
npm test
npm run build
```

`dist/` 可部署到任意静态托管，也可以整体复制到其他站点的子目录，通过页面或 iframe 打开。构建使用相对地址，不依赖 CDN、远程字体或服务端 API。请通过 HTTP/HTTPS 服务打开，浏览器通常不允许从 `file://` 启动 Worker。

### Unicode 字符表

- 使用 Unicode Consortium 的 **UCD 17.0.0**，包含独立记录、算法命名区间和 346 个区块。
- 按字符、`U+1F680`、`0x1F680`、十六进制 `1F680`、十进制 `#128640` 或英文名称检索；粘贴多个字符可逐个选择。
- 查看并复制字符、UTF-8 字节、UTF-16 码元、十进制值、HTML、JavaScript 与 CSS 转义。
- 支持补充平面、组合标记和控制/空白占位显示；不将 UTF-16 代理项当成有效标量。
- 显示取决于设备字体。某些生僻字、私用码点或较新的字符可能缺字；这不影响正确的码点、编码与复制。组合标记的虚线圆只是显示辅助。
- 数据随发行包提供。`npm run data` 从 Unicode 官方下载指定版本并生成紧凑 JSON；普通使用不会联系 Unicode 网站。

### 汉字数字重命名

- 普通、大写及传统形式：`第十二章 → 第12章`、`二〇二六 → 2026`、`壹佰零捌 → 108`；支持位数补齐与前缀。另有“提取数字置于前方”模式及最多处理前 N 段，延续原工具的两种用途。
- 目录名称与文件扩展名保持原样。逐位数字保留前导零；带单位的数字按明确位值计算，不猜测口语省略，例如“一百二”按 102 处理。
- 载入后只预览；冲突、Windows 保留名称或不合法单位序列不能执行，可以逐项取消选择。
- **ZIP 副本模式：**适用于现代浏览器，保留原件和相对目录结构。单次导出最多 **200 MB**；流式读取、可以停止。输出只包含选中的可处理项，不包含取消选择或无需改名的文件。
- **目录直接模式：**桌面 Chrome / Edge 的 File System Access API，需要 HTTPS 或 localhost、用户选择目录并单独允许写入。先预检，再逐文件写入新名称、流式 SHA-256 校验，最后移除原名称。不是 OS 原子 rename，不适合需要保留 ACL/ADS/原修改时间等元数据的场景；请勿让其他程序同时修改目录。
- 已完成项保留操作记录；停止或失败后可撤销完成项，连续操作按上一批逐批撤销。撤销会检查内容哈希，拒绝覆盖已有原名称，拒绝更改已被外部编辑的结果。记录可以下载，再载入并重新选择原目录继续恢复；目录访问权限由浏览器管理。
- 扫描有进度和停止按钮；单次最多 10,000 个文件、20,000 个目录条目、2,000 个子目录及 32 层深度，不处理目录名称。关闭页面前请保存操作记录；浏览器不会替你自动备份真实文件。ZIP 模式适合先试用规则。

## 实现

原生 HTML / CSS / JavaScript 组织界面，Vite 构建。Unicode 在模块 Worker 中建索引和检索；字符编码采用 Unicode 标量、TextEncoder 与 UTF-16 码元，算法命名覆盖 CJK 与 Hangul。重命名核心采用 BigInt 和纯函数；浏览器 File API / File System Access 处理本地文件，noble/hashes 做流式 SHA-256，fflate 写入 UTF-8 ZIP。

测试覆盖中文数字、错误单位、冲突、扩展名/目录保留、补充平面、代理对、官方数据范围、内容校验、撤销、停止、外部修改和 ZIP 完整性。开发服务器下的 `tests/browser-harness.html` 还可在浏览器私有 OPFS 中执行真实文件 API 检查；它只操作自己新建的临时样本目录，不访问个人文档。

## 历史来源

源于作者留存的 `unicode_table.exe` 与 `批量文件重命名工具 - 汉字数字转阿拉伯数字.exe`。本次未找到完整原工程；重命名工具通过静态反编译恢复了原入口的用途证据，原版有替换、数字前置和段数限制。因此当前版本是围绕原用途重新设计的网页实现，**不宣称直接升级或完整恢复旧源码**。旧 EXE 没有运行，恢复的字节码/反编译文本也不随仓库发布。

静态检查可确认旧字符表链接 Qt 5 Core / Gui / Widgets；旧重命名工具虽保存在名为“.net4.6 可执行程序集”的目录中，实际没有 CLR 元数据，PyInstaller 包索引显示 Python 3.5 入口。目录名字不作为技术栈结论。
